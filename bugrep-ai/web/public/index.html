How it works

Test Agent

Reads your bug report and code, finds the faulty function and writes strict regression tests.

Reproduce

BugRep runs the tests on your original code. They must fail, which proves the bug is real.

Fix Agent

Writes a minimal patch. It can't touch the locked tests; it can only change source code.

The same tests now pass. You review the diff, then download the fixed code and report.
